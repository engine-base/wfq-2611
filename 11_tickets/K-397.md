## 目的

チケットの詳細（`/tickets/[id]`・画面 tickets）の本文の「決定ログ」の区画を、決定を 1 件ずつ残せる部品にする（行為 A108・用事 J20「何をなぜ決めたかを遡りたい」）。今は作るときに書いた字が出るだけで、決定を足せない。

- 区画の見出しは区画の名前（既定「決定ログ」）。生きている決定があれば「決定ログ（2）」
- 作るときに書いた字は上に「作るときに書いた字：〈字〉」で残し、その下に決定の一覧（日付・決めた人・ひとこと・理由・元の書き込み）（代表の答え ⑳ a）
- 一覧の並びは、生きている決定を新しい順 → 改められた決定 → 取り消した決定（取り消しは線を引いて下に・⑰ a）
- 空「まだ決定はありません。決めたことと理由を残すと、あとから根拠として引けます」・読めない「決定を読み込めませんでした」と「もう一度読む」
- 「＋ 決定を足す」小窓：決めたこと（必須・字数の上限なし・D-130.1）・決めた人（既定は本人・ほかのメンバーを選べる）・ひとこと・理由（⑱ a）。「どこまで効かせる」の欄は持たない（取引先を持たず選び肢が「このチケットだけ」1 つになったため外した・answer=4961f0280e9a・PM の決め 2026-11-23）。AI の案の欄はグレーで「AI の案は、自分の AI と話す画面ができてから使えます」（⑯ a・D-145.9）
- 閲覧のみの人は一覧を読めるが、足せない（⑧ a「段や決定は変えられない」）

正の絵はモック `/dev/mock/f6/<状態>`（本番と同じ部品 `features/F6/decisions/views.tsx`・K-382 が本線に入れる）の dec-log・dec-empty・dec-add。見た目はモックの画面と本番の画面の写しを同じ幅（375・768・1440）で比べる（共通の道具 `apps/web/tests/k/stage2-match.ts` の matchMock・base は /dev/mock/f6）。
書き込みから決定にする・改める・取り消すは K-398、通しは K-399。

## 画面が読む値・送る値（正は口の葉 K-390。2026-11-20 切る段で K-390 の md に合わせた）

決定の一覧 `GET /api/v1/tickets/{id}/decisions` → `{ data: Decision[], meta: { can_write: boolean } }`（並びは口も同じ順で返す・K390-API-002）。Decision の 1 件（K-390 の 12 の鍵。状態の欄は無く、cancelled と superseded_by_id で決まる）：

| 欄 | 形 | 画面の使い方 |
|---|---|---|
| id | uuid | 行の鍵・改める／取り消すの的（K-398） |
| text・reason | string・string \| null | 決めたこと・「理由：…」 |
| decided_by | { id, display_name } \| null | 決めた人（外したメンバーでも名前が出る・D-128.96） |
| decided_note | string \| null | 決めた人の横の「（先方と合意）」 |
| decided_at | 時刻 | 日付「MM/DD」（日本時間）・並び |
| source | { id, at, deleted } \| null | 「元：やり取り MM/DD HH:MM →」（リンク #msg-<id>・at は元の書き込みの時刻を日本時間で）／deleted なら「元の書き込みは消されました」。at は K-390 が答えに足した（まとめ役が切る段でそろえた・K390-API-006） |
| （状態） | cancelled があれば取り消した・superseded_by_id があれば改められた・どちらも無ければ生きている | 札「改められた」「取り消した」・並び |
| superseded_by_id・revises_id | uuid \| null | 「新しい決定：〈字〉 ↑」・「MM/DD の決定を改めた」と札「改めた」（同じ一覧の中で引く） |
| cancelled | { at, by: { id, display_name }, reason } \| null | 「取り消し MM/DD 〈呼ばれ方〉：〈理由〉」（呼ばれ方は表示名の最初の語・D-128.58） |

決定を足す `POST /api/v1/tickets/{id}/decisions`：体 `{ text, reason, decided_by_member_id, decided_note }`（reason・decided_note は空なら null。promoted_to は送らない）。201 `{ decision, message_id }` → 決定の一覧を 1 回読み直す。断り（K-390）：422 E-VAL-042「決めたことを書いてください」（欄 text）／404 E-PAGE-001「決めた人は、この会社のメンバーから選んでください」（欄 decided_by_member_id・同じ会社の今のメンバーでない・drift 2026-11-20 16:51）（元の書き込みの 404 は K-398 の口の話）／403（書けない）／404（チケットが消された）／401。
