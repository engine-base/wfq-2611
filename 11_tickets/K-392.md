## 目的

チケットの詳細（`/tickets/[id]`）の右のパネルのタブ「やり取り」を押すと、そのチケットのやり取りが読めるようにする（行為 A107・D-128.45）。
書き込みと変更の記録と AI の実行と仕組みの行を **1 本の時系列（古い順・新しい物がいちばん下）** で出し、最初は **新しい方から 20 件**、それより前は「前の書き込みを見る（あと N 件）」で同じ件数ずつ足す（代表の直し answer=fabd031f9b37・PC の幅も同じ形）。
タブには **読んでいない数**、ほかの人の新しい書き込みには **「新しい」** を出し、タブを開いたら **最後に開いた時刻** を書く（代表の答え ⑬ answer=f5cd1647389f）。
狭い幅（1023 以下・パネルが本文の下）では **題名の下に「やり取り N ↓」** を出し、押すとやり取りまで動く（代表の答え ㉑）。

書く欄（K-393）・直す・消す・☆（K-394）・状態 ▾（K-396）・決定にする（K-398）は別の葉。この葉は、それらの葉が `views.tsx` を触らずに済むよう、部品に **値と押す関数を受ける口を先にまとめて足す**（下の「## 依存の理由」の「前へ移す」）。

- 先方（取引先）には社内のやり取りを見せない（D-125.122）のは口の側（K-383 の行の守り）。画面は答えを出すだけ

## 画面が読む値（正は口の葉 K-383・K-384）

一覧 `GET /api/v1/tickets/:id/timeline?limit=20[&before_at=…&before_id=…][&filter=talk|mine]` の data（古い順）の 1 件と meta：

| 欄 | 形 | 画面の使い方 |
|---|---|---|
| id・kind | string・"post" \| "change" \| "system" \| "run" \| "deleted" | 行の鍵・どの部品で出すか |
| at | 時刻 | 日付の区切り・時刻・前を読む before_at |
| actor | {member_id, display_name, call_name} \| null | 名前・顔の字 |
| message | {body, mentions[], notified[], quote: {id, excerpt} \| null, edited_at, stars, starred, is_new, decided, can_edit, can_delete} \| null | 書き込みの中身と印・「…」の出し分け（K-394） |
| changes | {field, from, to, note?}[] \| null | 変更の 1 行・書き込みと一緒に残った変更 |
| run | {id, summary, started_at, finished_at, minutes, result} \| null | AI の実行の 1 枚。result は状態の鍵（done・running・asking・stopped・cancelled・failed）で、字は画面が付ける：done「通った」・running と asking「動いている」・stopped と failed「止まった」・cancelled「取り消した」（**仮**・モックの「通った」に合わせた） |
| deleted | {by, author, by_manager} \| null | 消した跡 |
| meta.older_count・new_count・mine_count・post_count | number | あと N 件・タブの数・自分あて N・飛び先の N |

## 外に影響する手順

画面は口を呼ぶだけ（読むのは K-383・書くのは K-384）。呼んだ口が失敗したときの画面：

- S1: やり取りを読む口を呼ぶ（詳細を開いたとき・絞り込みを替えたとき）。失敗（503・500・404・網の切れ）したらパネルの中に「やり取りを読み込めませんでした」と「もう一度読む」（K392-UI-011）、401 ならログインへ（K392-UI-012）

- S3: 前の書き込みを読む口を呼ぶ。失敗したら知らせを出し、出ていた行とボタンはそのまま（K392-UI-007）
