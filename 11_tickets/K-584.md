## 目的

代表の決め（2026-11-22・D-150.61「出来合いの編集の部品が持つ機能を、こちらで絞らずに使う。色は自由・表の操作・下線・取り消し線・見出しの段・番号つき・寄せ・区切りの線など」）に合わせて、K-561 が作る文書の木（`packages/contracts/src/doc.ts`）の `validateDoc` と `docToText` を広げる。保存する文書が「節と印」を足しても、口（K-432・K-437）と画面（K-567・K-568・K-587・K-577）が同じ決まりで受ける・出せるようにするための葉。

足す物（決め `.ticket-flow/side-notes/段5-書き/v3-本文の道具-決め.md` の表）：

| 種類 | 足す物 | 形 |
|---|---|---|
| 節 | 番号つきの並び `orderedList` | 中身は `listItem`。`attrs.start` は任意（整数 1〜9999）。`listItem` の中にも入れ子にできる |
| 節 | 区切りの線 `horizontalRule` | 中身なし・attrs なし。doc の直下だけ |
| 節 | 見出しの段 | `heading` の `level` は 2・3・**4**（頁の h1 は題名なので 1 は使わない） |
| 節の attr | 文字の寄せ `textAlign` | 段落と見出しに任意。`left`・`center`・`right`・`justify` |
| 節の attr | 表のセルの結合 | `tableCell`・`tableHeader` に `colspan`・`rowspan`（任意・整数 1〜50）と `colwidth`（任意・整数 1〜2000 の並び・長さは colspan。colspan が無ければ 1）。見出しのセル `tableHeader` はどの行・列にも置ける |
| 印 | 下線 `underline`・取り消し線 `strike`・行の中のコード `code`・上付き `superscript`・下付き `subscript` | attrs なし |
| 印 | 文字の色 `color` | `attrs.color` は前の 3 つ（red・teal・amber）**か** `#rrggbb`（`^#[0-9a-f]{6}$`） |
| 印 | 背景の色 `highlight` | `attrs` は任意。あれば `{ color }` だけで、`color` は `#rrggbb`。無ければ前のまま（正本の黄） |

`docToText`：番号つきの並びは箇条書きと同じ扱い（「- 」・start の数は字に出さない）・区切りの線は字を出さない・印と寄せと結合は字に関わらない。

**K-561 で通る文書は全部そのまま通り、同じ text になる**（足すだけ。K584-DOC-013）。

## 前提と制約

分類: CRUD

- 置き場は K-561 と同じ（`packages/contracts/src/doc.ts` を直す・`packages/contracts/src/index.ts` から新しい名前を出す）。**口・DB・openapi は直さない**（下の「口と DB に要る直し」）
- **変えない物**：`{ doc, text }` の形・節の数に上限を持たない決め・入れ子 12・大きさ 1,048,576 バイト・text の上限・字の中の NUL を断る・薄い字（`attrs.ghost`）は text に入れない・リンクの守り（http・https・mailto だけ・長さ 2,048）・知らない節・印・鍵は断る・段落の中に節は置けない。**K-561 の試験の行（K561-DOC-001〜006・K561-DB-001〜017）は変えない**（ただし 004 の 3 つの値だけは下の「前からの試験を替えた所」のとおり）
- **色の値は style にそのまま入れても安全な形だけ通す**：`#rrggbb` の小文字 16 進 6 桁だけ（`DOC_HEX_COLOR = /^#[0-9a-f]{6}$/`・m と g の旗を付けない＝末尾の改行を許さない）。`rgb()`・`hsl()`・名前・`url()`・`var()`・`#rgb`・大文字・8 桁・空白や `;` を含む値は断る。画面（K-577）は、通った値だけを style に入れる。サーバーに前から在った物で形に合わない値は、画面が色を付けずに字だけ出す（K-577）
- 背景の色の旧い 3 色の名前（red・teal・amber）は使わない（文字の色の旧い名前だけが残る。理由：背景の色は新しい印で、名前の背景は前から無い）
- 名前（K-567・K-568・K-587・K-577・K-432 が使う。変えない）：`DOC_ALIGNS`（`["left","center","right","justify"]`）・`DOC_HEX_COLOR`・`DOC_HEADING_LEVELS`（`[2,3,4]`）・`DOC_COLSPAN_MAX`（50）・`DOC_COLWIDTH_MAX`（2000）・`DOC_START_MAX`（9999）。型 `HeadingNode.attrs.level` は 2 | 3 | 4・`Mark` に印 5 つと色の型・`OrderedListNode`・`HorizontalRuleNode` を足す。どれも `@kaname/contracts` の入口（`index.ts`）から出す
- 表のセルの `colwidth` の長さは colspan と同じ（colspan が無ければ 1）。1 行の中のセルの数・結合で空いたマスの整合は確かめない（編集の部品が決める。確かめると前から通る表が通らなくなる）
- 理由は断るときの言葉に型の名前を入れる：節は `orderedList`・`horizontalRule`・`heading`、属性は `<型> の attrs …`、色は `color`・`highlight`（試験は理由の中の言葉で見る）
